Entry for the make.fun competition **Notes From a Passive-Aggressive Fridge** — one
funny passive-aggressive note a smart fridge leaves for its owner.

`main.py` (stdlib only) writes the note to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (default `output`).

The note is dry, petty and specific: the fridge logs the 2 a.m. door-opening,
times the 47-second stare, and lets the yogurt witness it.
